Método tradicional de desenvolvimento de software - Cascata | Waterfall

  • Mais valor à documentação do que ao software em si. O modelo Waterfall é um modelo de desenvolvimento de software linear e sequencial, onde cada fase do processo deve ser concluída antes que a próxima fase possa começar. As fases típicas incluem: Requisitos, Design, Implementação, Testes, Implantação e Manutenção.
  • Mais valor ao que está no contrato

Método ágil de desenvolvimento de software - Agile | SCRUM

  • Mais valor ao software em si do que à documentação. O modelo Agile é um modelo de desenvolvimento de software iterativo e incremental, onde o desenvolvimento é realizado em ciclos curtos chamados sprints. Cada sprint resulta em um incremento funcional do software.
  • Mais valor ao trabalho feito
  • poder ter regularmente mais valias no código
  • mais valor ao cliente | poder receber feedback do cliente
  • mais valor à equipa
